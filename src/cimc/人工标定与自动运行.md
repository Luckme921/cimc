# 人工标定一次，随后自动处理 ABB 多条请求

启动命令（现场需先确认 ABB 程序处于安全调试状态）：

```bash
source /opt/ros/humble/setup.bash
source /home/mini/x86_ros2_ws/install/setup.bash
ros2 launch cimc camera_weld_operator_abb.launch.py workflow_mode:=manual
```

人工模式启动后，ABB TCP 接收节点先监听 `192.168.3.100:45000`，以免机器人因连接失败退出。此时**不接受**拍照任务：过早的 `START_CAPTURE` 会收到 `TRAJECTORY_ERROR:OPERATOR_NOT_READY`，不会排队或复用旧拍照位姿。机器人程序应在操作员完成确认、终端依次出现 `Camera ready`、`Hand-eye bridge ready` 和“任务协调节点已就绪”后才发送拍照请求；TCP 连接成功不等于系统允许拍照。现有 RAPID 程序如只会连接后立即发送、且不识别上述错误帧，应由机器人开发者增加等待/重试逻辑。

操作窗口提供两条路径：

1. 已有固定 ROI/偏移，无需修改：直接点“确认配置，启动自动链路”。
2. 需要调节：点“实时预览相机并画 ROI”，在实时画面中用 T/B/D/K、X/Y/Z、N/M、`[`/`]` 调 ROI；按 S 保存，按 Q 退出，窗口自动带入本次 ROI 和 PLY。实时预览的网络/深度范围/增益/曝光/帧时间读取 `src/chishine_camera_ros2/config/camera.yaml`，当前现场对应 100–600 mm、增益 2、曝光 14000 μs、帧时间 20000 μs、显示 600000 点；S 的保存目录与 ROS 相机节点的点云目录一致，默认 `/home/mini/scut_weld_data/pointclouds`。也可选历史 PLY。修改 ROI、算法模式和各组点的 X/Y/Z 偏移后，点“用当前参数离线预览”。系统会尝试在 VS Code 中打开**算法原生** `operator_preview_序号_result.ply`，不再在点云上叠加拥挤的文字；独立表格列出 P 序号、特征类型、`position_offset_group`、实际偏移和点来源。选中表格点后，可生成仅该点带青色十字的高亮 PLY，原始结果不变。预览历史会保留每次结果，不互相覆盖；可重新打开比对。若 VS Code 未自动打开，可复制表格上方路径手动打开。可反复修改、预览；当前值成功预览后才能确认。确认前会再弹窗说明：之后多次 ABB 请求不再逐次询问。

S 保存的 PLY 在相机点云目录；离线 CSV/result.ply、`extract_序号.log`、批准记录、配置修改前备份在工作区 `operator_sessions/时间戳/`。每次离线预览读取**当前界面输入值**和当前选中 PLY，但不修改正式配置。最终确认才对 `src/weld_seam_perception/config/weld_seam.yaml` 中真正改变的参数做定点修改，其他注释及参数保留；焊缝节点在确认后启动，因而读取到新配置。任何值变化都会使此前预览失效，必须再次预览；若完全不改配置且未选择 PLY，可直接确认而不重写 YAML。预览点数若为 0 或超过 ABB 的 100 点上限，不能确认。算法给出的 `WARNING:`（例如偏移后点位低于检测底面）会在复核页和最终确认弹窗显示；此类提示需要人工核对点位，不代表机械臂可达或已经安全验证。

固定夹具模式沿用原有 launch 和当前 YAML，不打开人工窗口：

```bash
ros2 launch cimc camera_weld_operator_abb.launch.py workflow_mode:=fixed
```

也可以继续直接用旧命令 `ros2 launch cimc camera_weld_handeye_abb_test.launch.py`。

计时：算法每次输出 `Total time including PLY I/O`；ABB 端到端计时从完整 `START_CAPTURE` 收到起，到轨迹 `sendall` 完成为止，终端显示 `[ABB端到端耗时]`，话题是 `/abb/task_timing`。`/abb/tx_status` 只能说明本机 socket 写入成功，机器人实际 ACK 与执行结果仍应由 ABB 端验证。

人工预览程序独占相机，所以 Q 退出预览后才允许确认并启动 ROS 相机节点。人工模式仅多出启动前配置步骤；运行阶段与旧链路一致。该 launch 不启动焊机或电机节点；但如果 ABB 自己的程序会收到轨迹后运动，仍须由现场人员确认安全模式。
