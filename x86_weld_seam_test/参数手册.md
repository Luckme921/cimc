# 焊缝 SDK 2.3.1 全参数手册

本文逐项解释 `config/default.conf` 的 88 个键。除模式字符串外，距离/坐标参数在当前点云约定下均以 mm 为主；角度为度。命令行可用 `--set key=value` 临时覆盖，ROS 2 可把同样字符串加入 `algorithm_overrides`。

## 1. 三种坐标不要混淆

- ROI 的 XYZ：输入 PLY/相机坐标系。
- `offset.*.x/y/z`：算法识别出的工件局部右手坐标系。
- CSV `x,y,z`：最终再转换回 PLY/相机坐标系输出。

工件局部轴：

- `+X = N_tangent`：CSV 焊缝排序/前进方向；
- `+Y = -N_side`：从波纹板指向 L 侧板/开放安全侧；
- `+Z = N_bottom`：离开蓝色底板向上。

相机整体平移/旋转时，算法根据底面和侧面重新构建工件轴，所以四类偏置和姿态仍随工件转动；ROI 不会随工件转动，换拍照位后需重新检查。

## 2. ROI 参数（7 个）

| 参数 | 默认值 | 实际意义 |
|---|---:|---|
| `roi.enable` | `false` | `false` 使用全视野；`true` 在体素/平面前先裁剪，能减少时间和干扰 |
| `roi.min_x` | `-inf` | 保留 PLY X 大于等于该值的点 |
| `roi.max_x` | `inf` | 保留 PLY X 小于等于该值的点 |
| `roi.min_y` | `-90` | ROI 开启时的 PLY Y 下界 |
| `roi.max_y` | `-30` | ROI 开启时的 PLY Y 上界 |
| `roi.min_z` | `-inf` | PLY Z 下界 |
| `roi.max_z` | `inf` | PLY Z 上界 |

所有下界必须小于等于上界。`roi.enable=false` 时边界不参与处理。先用可视化确定相机轴方向，再收紧 ROI；不要把工件局部 Y 的正负直接套到相机 Y。

## 3. 法向量参数（4 个）

| 参数 | 默认值 | 实际意义 |
|---|---:|---|
| `normal.mode` | `auto` | `auto` 优先复用 PLY 法向并自动回退；`recompute` 强制重算；`reuse` 质量不足即报错 |
| `normal.reuse_min_valid_ratio` | `0.995` | XYZ 有效点中，有限非零法向所占最低比例；体素后还会复查 |
| `normal.k_neighbors` | `20` | 重算法向时每点 K 近邻数量；较大更平滑但慢并可能抹平小圆角 |
| `normal.thread_count` | `0` | PCL OMP 线程数；`0` 由运行库自动选择，正整数用于限制 CPU |

复用前会把 `nx/ny/nz` 映射成 PCL 标准名、单位化，并统一朝向相机光心。修改阈值不能修复错误法向方向；怀疑相机法向质量时应先使用 `recompute` 对照。

## 4. 主焊缝提取参数（5 个）

| 参数 | 默认值 | 实际意义 |
|---|---:|---|
| `primary.z_filter_threshold` | `0.5` | 候选侧面点必须高于底板该距离，抑制 L 底板直焊缝/底面混入 |
| `primary.y_filter_threshold` | `2.0` | 候选点必须离 L 侧面局部原点超过该距离，抑制侧板点；当前 3–4 mm 间隙下取 2 mm |
| `primary.plane_search_leaf_size` | `1.0` | RANSAC 发现方向时的辅助粗体素；最终平面参数仍回到 0.5 mm 点云精修 |
| `primary.plane_search_min_inliers` | `300` | 粗平面最小支持点上限参数；代码还会按当前点数自适应夹紧 |
| `primary.side_origin_low_quantile` | `0.002` | 用侧向投影低分位而非单点最小值设 `y_local=0`，减弱飞点影响 |

粗平面搜索失败会自动回退全分辨率 RANSAC。不要仅因黄色/橙色显示不完全一致就调这些值；只要蓝色底面、红色焊缝和局部轴稳定，颜色分簇边界的小差异通常不影响最终结果。

## 5. 二次特征提取参数（24 个）

| 参数 | 默认值 | 实际意义 |
|---|---:|---|
| `feature.profile_bin_width` | `0.8` | 沿工件 X 把红点压成一维轮廓的分箱宽度，略大于 0.5 mm 体素 |
| `feature.flat_normal_dot_min` | `0.80` | 判定上下底平段的法向点积下限 |
| `feature.diagonal_normal_dot_min` | `0.12` | 判定左右腰斜段时切向法向分量的最低绝对值 |
| `feature.bin_label_vote_ratio` | `0.45` | 一个分箱被某类法向标签占据的最低投票比例 |
| `feature.min_segment_bins` | `3` | 标签连续段至少包含的分箱数，过滤短噪声游程 |
| `feature.min_segment_span` | `1.2` | 连续段在局部 X 上的最低实际跨度 |
| `feature.local_fit_half_window_bins` | `8` | 用轮廓斜率纠正法向标签时，中心两侧各取的分箱数 |
| `feature.local_fit_radius` | `10.0` | 局部二维线拟合的最大 X 搜索半径 |
| `feature.local_line_max_median_residual` | `0.65` | 局部线残差中位数上限，过大认为不是可靠直线 |
| `feature.flat_profile_slope_max` | `0.22` | `local_y/local_x` 斜率绝对值低于此值认为是平段，约 12.4° |
| `feature.flat_segment_max_length` | `135.0` | 上/下底直段宽松最大长度；工件约 110 mm、保证不超过 130 mm |
| `feature.waist_segment_max_length` | `70.0` | 腰段宽松最大长度；真实约 45 mm，用于阻止跨周期连接 |
| `feature.max_hole_bridge` | `70.0` | 两可靠段之间允许桥接的最大拍照空洞；仍受角度/长度/交点约束 |
| `feature.max_corner_extrapolation` | `18.0` | 两直线理论交点允许超出实际支持段端部的最大距离 |
| `feature.min_corner_angle_deg` | `10.0` | 两相邻拟合线构成有效角点的最小夹角 |
| `feature.duplicate_corner_merge_distance` | `18.0` | 同类型近邻检测小于此距离视为同一圆角；2.2.2 同时把它作为相邻物理角的最小安全间距，阻止短假线段插入多余点 |
| `feature.corner_fit_support_distance` | `5.0` | 角点两侧约 ±5 mm 的拟合支持位置；用于构造稳定交点/安全几何 |
| `feature.recessed_chord_search_radius` | `7.0` | 凹角安全弦两端在红色轮廓上的搜索半径 |
| `feature.safe_transition_offset_y` | `20.0` | 首末安全过渡点相对第一/最后真实焊点沿工件 +Y 避让量 |
| `feature.safe_transition_offset_z` | `20.0` | 首末安全过渡点沿工件 +Z 抬高量；工件 X 保持相同 |
| `feature.recessed_arc_search_radius` | `10.0` | 凹角在理论交点附近寻找真实圆弧红点的邻域半径 |
| `feature.bottom_z_quantile` | `0.10` | 邻域内用局部 Z 的低 10% 分位靠近底板，不直接取极小离群点 |
| `feature.low_z_xy_tolerance` | `1.5` | 选择靠底红点时允许的局部 XY 几何容差 |
| `feature.protruding_is_larger_local_y` | `false` | `false` 表示靠 L 侧板、较小 local Y 为凸层；相机变化不应随意改它 |

这些参数互相约束。提高 `max_hole_bridge` 可能补大空洞，也可能跨周期；提高重复合并距离可能去重，也可能误删距离很近的真实相邻角。因此一次只改一项，并保存输入 PLY、配置、终端日志和输出 PLY。

## 6. 路径输出参数（14 个）

| 参数 | 默认值 | 实际意义 |
|---|---:|---|
| `path.mode` | `feature_points` | `feature_points` 保留 2.2.2 四类拐点路径；`adaptive_contour` 启用连续轮廓备用算法 |
| `path.straight_spacing` | `12.0` | 低曲率直线段目标点距 |
| `path.corner_spacing` | `4.0` | 转角/曲率区域目标点距，必须不大于直线点距 |
| `path.corner_influence_radius` | `15.0` | 曲率区前后按弧长由密集点距渐变到直线点距的范围 |
| `path.curvature_window` | `10.0` | 计算轮廓转角和姿态切线时，当前点前后使用的弧长窗口 |
| `path.curvature_threshold_deg` | `8.0` | 窗口内转角达到该角度后视为曲率区 |
| `path.orientation_smoothing_radius` | `20.0` | 仅对姿态切线做弧长中心平滑的半径；不修改任何焊缝点 XYZ，`0` 表示关闭窗口平滑 |
| `path.max_orientation_step_deg` | `6.0` | 相邻连续轮廓点允许的最大切线角变化；使用首末双向限幅，最终四元数步长通常小于该值 |
| `path.smoothing_half_window_bins` | `8` | 鲁棒轮廓中值平滑半窗口，默认约对应数毫米 |
| `path.outlier_max_distance` | `3.0` | 原始 profile bin 偏离局部 YZ 中值超过该距离时先按飞溅/点焊离群替换 |
| `path.max_bridge_gap` | `15.0` | 相邻轮廓 bin 最大允许空洞；小孔洞线性连接，大孔洞直接失败而非跨越焊接 |
| `path.max_points` | `100` | 单条轨迹总点数上限，包含首末安全点；有效范围 4–100 |
| `path.work_angle_deg` | `45.0` | 连续轮廓全部焊接点统一工作角，局部开放方向仍随轮廓变化 |
| `path.lead_angle_deg` | `0.0` | 连续轮廓全部焊接点统一前倾/后倾角 |

自适应模式从红色焊缝点按工件 X 分箱，每个分箱先取中值，再做小窗口离群抑制。采样不会依赖四类拐点是否检测完整，也不会为了满足点数上限截断末端；若预计超过 `path.max_points`，直线和曲率点距按相同比例放大后重新完整采样。姿态切线由固定弧长有向弦计算，避免近竖直腰段的普通斜率回归数值失稳；随后只在角度域平滑和限幅，不移动路径位置。当前 ABB `traj_points` 最大 100，因此 SDK 不允许把上限配置为 101 或更大。

`path.max_bridge_gap` 与旧的 `feature.max_hole_bridge` 作用不同：前者是连续轮廓轨迹实际允许跨过的数据缺口，涉及机器人安全，默认更严格；后者只服务于四类拐点模式的直线段推断。

## 7. 姿态参数（11 个）

四组含义：`protruding_left/right` 为凸角左/右腰，`recessed_left/right` 为凹角左/右腰。左/右按 CSV 前进方向下腰部局部斜率定义，不是相机画面的左/右。

| 参数 | 默认值 | 实际意义 |
|---|---:|---|
| `orientation.protruding_left.work_angle_deg` | `45` | 凸左处 TCP→枪体轴与蓝色底板平面夹角 |
| `orientation.protruding_right.work_angle_deg` | `45` | 凸右工作角 |
| `orientation.recessed_left.work_angle_deg` | `45` | 凹左工作角；增大通常使枪体更竖直，但必须仿真/低速验证 |
| `orientation.recessed_right.work_angle_deg` | `45` | 凹右工作角 |
| `orientation.protruding_left.lead_angle_deg` | `0` | 凸左沿 CSV 前进方向的前倾角；正向前、负向后 |
| `orientation.protruding_right.lead_angle_deg` | `0` | 凸右前倾角 |
| `orientation.recessed_left.lead_angle_deg` | `0` | 凹左前倾角 |
| `orientation.recessed_right.lead_angle_deg` | `0` | 凹右前倾角 |
| `orientation.tool_positive_z_points_from_tcp_to_body` | `true` | `true` 表示机器人工具 +Z 从 TCP 指向枪体；实际定义相反时改 `false` |
| `orientation.tool_x_reference` | `workpiece_x` | `workpiece_x` 让工具 X 参考工件焊接前进轴；`corner_bisector` 恢复 2.2.0 的局部角平分线行为 |
| `orientation.tool_x_points_along_positive_workpiece_x` | `true` | 工具 X 参考工件 `+X`；设为 `false` 时参考工件 `-X`，仅在上一项为 `workpiece_x` 时生效 |

工作角必须在 `(0,90)`，前倾角绝对值小于 85°。若新相机拍照后白色枪体轴落在波纹板内部，先核对工具 +Z 定义；只有实际 TCP 坐标轴定义相反时才切换 Tool Z 布尔值。

`workpiece_x` 模式保持 Tool Z 的工作角和避让方向不变，再将工件 `+X/-X` 投影到垂直于 Tool Z 的平面作为 Tool X，并按右手系生成 Tool Y。这样可减少角点几何引起的绕焊枪中心轴滚转。由于三根工具轴必须正交，当工件 X 与 Tool Z 不垂直时，最终 Tool X 是其正交投影而非未经处理的原向量。该策略改善姿态连续性，但机器人是否可达仍取决于关节限位、机器人构型、奇异点和碰撞约束。

## 8. 七组位置偏置（21 个）

每组都有 `.x/.y/.z`，分别沿工件局部 X/Y/Z。它们只移动最终路径点和可视化十字中心，不参与平面、红色焊缝和角点识别。

| 组 | 当前 XYZ | 作用 |
|---|---|---|
| `offset.start_transition` | `0,0,0` | 起始安全过渡点二次微调 |
| `offset.end_transition` | `0,0,0` | 结束安全过渡点二次微调 |
| `offset.protruding_left` | `2.5,0,0` | 凸左真实焊点微调；当前用户实测 X 为 +2.5 mm |
| `offset.protruding_right` | `-0.5,0,0` | 凸右真实焊点微调 |
| `offset.recessed_left` | `0,1,0` | 凹左沿开放安全侧 +Y 1 mm |
| `offset.recessed_right` | `0,1,0` | 凹右沿开放安全侧 +Y 1 mm |
| `offset.adaptive_contour` | `0,0,0` | 连续轮廓全部焊接采样点的统一偏置 |

例如 `offset.recessed_left.y=1.0` 是沿工件安全侧，不是相机固定 Y 加 1 mm。改变相机姿态时无需因为 PLY 轴变化而重新交换偏置；若分类本身错，应先排查局部坐标/法向，不要用偏置掩盖分类问题。

连续轮廓模式额外使用 `offset.adaptive_contour.x/y/z`，默认均为 `0`。所有连续焊接采样点使用同一组偏置，避免经过四类几何分界时出现位置阶跃；首末安全点会先继承这组偏置，再叠加 `offset.start_transition.*` 或 `offset.end_transition.*`。

## 9. 可视化参数（2 个）

| 参数 | 默认值 | 实际意义 |
|---|---:|---|
| `visualization.marker_radius` | `8.0` | 粉红三维十字星每条单侧臂长；中心才是 CSV 精确点 |
| `visualization.body_axis_length_mm` | `25.0` | 白色 TCP→枪体轴显示长度；`0` 关闭 |

两项只影响调试 PLY，不改变 CSV 位置/姿态。

## 10. 推荐调参顺序

1. `roi.enable=false`、`normal.mode=auto`，先确认旧样本回归稳定。
2. 用同一 PLY 比较 `auto` 与 `recompute`，确认红线、四类点、CSV一致。
3. 设置 ROI，只比较速度和结果，不先改几何阈值。
4. 默认保持 `path.mode=feature_points` 回归已有现场结果；需要曲率轮廓时再切换 `adaptive_contour`，先只检查 CSV/可视化和点数，不接机器人运动。
5. 拐点模式确认四类分类后再调对应偏置；连续模式只调 `offset.adaptive_contour.*`。
6. 确认机器人 TCP +Z 定义，再确认 Tool X 使用工件 `+X` 还是 `-X`，最后调工作角/前倾角。
7. 只有真实出现漏角、重复角或空洞失败时，才按对应现象小幅修改 `feature.*` 或 `path.*`。

任何生产参数变更都建议记录：相机序列号/固件、PLY 文件、SDK 版本、完整配置、终端分阶段时间、结果 CSV 和可视化 PLY。
